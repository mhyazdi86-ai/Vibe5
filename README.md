## 🎧 About the Project

**Vibe5** is a music discovery platform built around a simple idea: making it easier to explore artists and discover the music that defines their sound.

The project started as an idea, gradually took shape through UI/UX design in Figma, and was then brought to life through front-end development.

More than just building a website, Vibe5 is an opportunity to combine visual design, user experience, and front-end development in one project.

The current version focuses on the homepage and its visual experience, while the platform's planned features are being developed.
